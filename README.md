# AJKOOL · Descarga para Android

AJKOOL revisa con una foto las hojas y frutas de sus cítricos (naranja, china, limón, toronja y naranja agria) y le dice qué hacer. **Funciona sin internet**: sólo hace falta internet para bajarla.

## ⬇️ Descargar

**[Bajar AJKOOL para Android (77 MB)](https://github.com/sabrinasalomon/ajkool-descargas/releases/latest/download/ajkool.apk)**

## 📲 Cómo instalarla

1. Toque el enlace de arriba y espere a que baje el archivo `ajkool.apk`.
2. Abra el archivo (en las notificaciones o en "Descargas").
3. Si el teléfono dice que no puede instalar apps de esta fuente, toque **Ajustes** y active **Permitir de esta fuente**. Es normal: la app no viene de la tienda de Google.
4. Regrese y toque **Instalar**.
5. Busque el icono rojo con la hoja y ábralo. La primera vez le pedirá permiso para usar la cámara.

También se puede pasar de un teléfono a otro con WhatsApp, Bluetooth o una memoria USB.

## 📷 Cómo usarla

- Tome la foto **de cerca**: una hoja, un brote o una fruta, llenando el cuadro.
- Busque **buena luz** y no se mueva.
- Si dice "Puede ser…" o "No sé si está sana", tome otra foto más de cerca.

## ⚠️ Importante

- **Es una versión de prueba.** La app ayuda, pero puede equivocarse: aprendió sobre todo con fotos públicas y todavía pocas de Teabo. Ante una duda seria, pregunte a alguien que sepa.
- **El texto en maya es un borrador** y falta que lo revise una persona hablante de Teabo.
- Todavía **no tiene audios**: las bocinas aparecen apagadas.
- Sólo para teléfonos Android. Para iPhone todavía no hay forma de instalarla.
